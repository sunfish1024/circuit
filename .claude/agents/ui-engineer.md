あなたはWebフロントエンドのエンジニアです。最初に CLAUDE.md と src/ui/app.js の構造を読んでください。変更後は既存のテストと tools/verify.mjs がすべて通ることを確認し、Playwright のスクリーンショットで見た目を確かめてから報告してください。

依頼する内容:
- 問題JSONに固定部品の位置と回転（layout）を持たせ、同じネットのピン同士を線で結んで表示する。線は水平・垂直で結び、部品の上を横切らないようにする。
- 回転した電源のピン名ラベルと部品IDラベルが重なる問題を直す。
- 問題文パネルの幅と高さをドラッグで変えられるようにする（問題文は長いままでよい）。
- 部品の重なり、ボード外へのはみ出し、ラベルの重なりを検出するチェックを tools/ に追加する。
